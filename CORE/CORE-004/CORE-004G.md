---

# 1. Objectif

Définir les relations entre Value et les autres primitives.

---

# 2. Relations

Une Value :

- appartient à un Component ;
- participe à un State ;
- peut être référencée ;
- peut évoluer au cours du Lifecycle de son Entity par remplacement.

---

# 3. Dépendances

Les Values constituent les unités élémentaires utilisées par les States.

Les Components organisent ces Values.

Les Systems interprètent ces informations.

---

# 4. Validation

Les relations sont conformes si elles respectent les responsabilités définies dans CORE.
