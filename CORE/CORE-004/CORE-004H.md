# 1. Objectif

Illustrer la notion de Value sans introduire de règles métier.

---

# 2. Exemples

Les éléments suivants peuvent être représentés par une Value :

- un nombre ;
- un texte ;
- un booléen ;
- une date ;
- une durée ;
- une référence.

Ces exemples illustrent des catégories de données, sans imposer de format ou de technologie.

---

# 3. Principe

Les exemples présentés dans ce document sont illustratifs.

Ils ne constituent pas une liste exhaustive.
