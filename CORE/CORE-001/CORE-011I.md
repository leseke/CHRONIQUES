# CORE-001-I — Références

> Version : 1.0
>
> Statut : Fondation
>
> Type : Références
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les relations documentaires entre CORE et les autres bibliothèques du projet.

---

# 2. Références amont

CORE s'appuie sur :

- MASTER
- STANDARDS

Ces bibliothèques définissent respectivement la vision et les conventions.

---

# 3. Références aval

Les bibliothèques suivantes utilisent les concepts définis par CORE :

- GDB
- ACT
- PLN
- TECH
- QA
- UX
- LORE
- ART
- AUDIO
- PROD
- MKT

---

# 4. Principe

CORE ne référence jamais des concepts métier.

Les références sont toujours descendantes.

---

# 5. Références croisées

Chaque document des bibliothèques dépendantes doit référencer les primitives de CORE qu'il utilise.

---

# 6. Traçabilité

Toute règle métier doit pouvoir être reliée aux primitives concernées.

---

# 7. Validation

Le document est conforme si :

✓ les références sont cohérentes ;

✓ les dépendances sont unidirectionnelles ;

✓ aucune boucle documentaire n'existe.
