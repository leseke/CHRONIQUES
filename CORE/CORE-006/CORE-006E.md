# CORE-006-E — Nature

> Version : 1.0
>
> Statut : Fondation
>
> Type : Principes
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir la nature conceptuelle d'une Relation.

---

# 2. Nature

Une Relation représente un lien.

Elle ne représente jamais une Entity.

---

# 3. Autonomie

Une Relation possède sa propre existence conceptuelle.

Son existence dépend toutefois des Entities qu'elle relie.

---

# 4. Indépendance

Une Relation peut évoluer.

Les Entities concernées peuvent rester inchangées.

---

# 5. Neutralité

Une Relation ne possède :

- aucun comportement ;
- aucune décision ;
- aucune logique.

---

# 6. Validation

La définition est conforme si la Relation reste une primitive descriptive.
