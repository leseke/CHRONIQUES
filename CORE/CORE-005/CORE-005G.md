# CORE-005-G — Invariants

> Version : 1.0
>
> Statut : Fondation
>
> Type : Invariants
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les propriétés toujours vraies de la primitive State.

---

# 2. Invariants

## Invariant 1

Un State représente toujours une condition.

---

## Invariant 2

Un State est composé de Values.

---

## Invariant 3

Un State est exclusivement descriptif.

---

## Invariant 4

Un State ne contient aucune logique métier.

---

## Invariant 5

Un State peut évoluer sans modifier la responsabilité du Component.

---

## Invariant 6

Les Values d'un même State décrivent une condition cohérente.

---

# 3. Validation

Toute évolution de CORE doit préserver ces invariants.
