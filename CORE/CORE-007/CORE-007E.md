# CORE-007-E — Temporalité

> Version : 1.0
>
> Statut : Fondation
>
> Type : Principes
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir la relation entre Event et Time.

---

# 2. Principe

Tout Event appartient au Time.

Sans Time, un Event ne peut être ordonné.

---

# 3. Instant

Chaque Event est associé à un instant.

CORE ne définit pas la représentation de cet instant.

---

# 4. Ordonnancement

Le Time permet d'établir un ordre entre plusieurs Events.

Il ne définit pas leur causalité.

---

# 5. Simultanéité

Plusieurs Events peuvent partager le même instant.

Leur ordre relatif relève des bibliothèques spécialisées.

---

# 6. Validation

La temporalité est conforme si :

✓ chaque Event est situé dans le Time ;

✓ le Time permet leur ordonnancement.
