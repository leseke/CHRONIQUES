# CORE-000-H — Diagrammes

Le modèle conceptuel peut être résumé par les questions fondamentales :

| Primitive | Question |
|-----------|----------|
| Entity | Qui / Quoi ? |
| Component | De quoi est-il constitué ? |
| Value | Quelle information ? |
| State | Dans quel état ? |
| Relation | Avec quoi est-il lié ? |
| Event | Que s'est-il passé ? |
| Time | Quand ? |
| Space | Où ? |
| Lifecycle | Comment évolue-t-il ? |

Ces questions sont mutuellement exclusives et couvrent le périmètre du Kernel.
