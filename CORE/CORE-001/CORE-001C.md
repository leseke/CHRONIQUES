# CORE-001-C — Les primitives

---

Les primitives officielles de Chroniques sont :

Entity

Identity

Component

State

Value

Relation

Action

Intent

Plan

Event

Time

Space

Reference

Lifecycle

---

Ces primitives sont atomiques.

Aucune primitive ne peut être déduite des autres.

---

Toute bibliothèque du projet construit ses modèles exclusivement à partir de ces primitives.

---

Toute nouvelle primitive nécessite une décision d'architecture (ADR).

---

Une primitive ne décrit jamais un cas particulier.

Elle décrit une propriété universelle du système.
