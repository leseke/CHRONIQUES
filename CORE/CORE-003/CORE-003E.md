# CORE-003-E — Nature du Component

> Version : 1.0
>
> Statut : Fondation
>
> Type : Principes
>
> Bibliothèque : CORE

---

# 1. Objectif

Préciser la nature conceptuelle d'un Component.

---

# 2. Neutralité

Tous les Components appartiennent à une unique primitive : Component.

CORE ne définit aucun sous-type officiel de Component.

---

# 3. Utilisation

Les bibliothèques dépendantes peuvent utiliser différents modèles de Components selon leurs besoins.

Ces modèles ne modifient pas la définition de la primitive.

---

# 4. Indépendance

La nature d'un Component est déterminée par son contenu et son utilisation, jamais par son type.

---

# 5. Extensibilité

De nouveaux modèles d'utilisation peuvent être introduits sans modifier CORE.

---

# 6. Validation

La primitive Component reste unique et universelle.
