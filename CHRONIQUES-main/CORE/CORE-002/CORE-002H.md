# 1. Objectif

Définir les interactions de la primitive Entity avec les autres primitives du Kernel.

---

# 2. Relations

Une Entity :

- est composée de Components ;
- possède un Lifecycle ;
- possède un State au travers de ses Components ;
- participe à des Relations ;
- est concernée par des Events ;
- existe dans le Time ;
- peut être localisée dans le Space ;
- peut être référencée par une Reference.

---

# 3. Dépendances

Entity constitue le point central du modèle conceptuel.

Les autres primitives complètent ou décrivent son existence.
