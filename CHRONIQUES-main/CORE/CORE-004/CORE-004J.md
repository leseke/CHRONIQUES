# CORE-004-J — Gouvernance

> Version : 1.0
>
> Statut : Fondation
>
> Type : Gouvernance
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les règles d'évolution de la primitive Value.

---

# 2. Principe

La définition d'une Value doit rester simple, atomique et universelle.

---

# 3. Évolution

Toute évolution doit :

- préserver l'atomicité ;
- respecter les invariants ;
- être documentée ;
- être validée par une ADR.

---

# 4. Compatibilité

Les évolutions ne doivent pas modifier les responsabilités des autres primitives.

---

# 5. Dépréciation

Une propriété peut être dépréciée.

La primitive Value ne peut être supprimée.

---

# 6. Validation

Toute modification doit préserver le rôle fondamental de Value comme unité élémentaire d'information.
