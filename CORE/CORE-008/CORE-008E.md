# CORE-008-E — Ordonnancement

> Version : 1.0
>
> Statut : Fondation
>
> Type : Principes
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir le rôle de Time dans l'ordonnancement des faits.

---

# 2. Principe

Time fournit un ordre entre les Events.

Il ne définit pas leur causalité.

---

# 3. Antériorité

Pour deux Instants distincts :

- l'un peut précéder l'autre ;
- ou le suivre.

---

# 4. Simultanéité

Plusieurs Events peuvent être associés au même Instant.

Leur ordre interne n'est pas défini par CORE.

---

# 5. Continuité

CORE ne suppose ni un temps continu ni un temps discret.

Cette décision appartient à TECH.

---

# 6. Validation

L'ordonnancement est conforme si Time permet d'établir une chronologie.
