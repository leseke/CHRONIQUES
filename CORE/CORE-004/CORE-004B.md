# CORE-004-B — Définition

> Version : 1.0
>
> Statut : Fondation
>
> Type : Définition
>
> Bibliothèque : CORE

---

# 1. Définition

Une Value est une donnée élémentaire ne pouvant être décomposée davantage dans le modèle conceptuel.

---

# 2. Nature

Une Value ne décrit qu'une seule information.

Elle ne possède aucune responsabilité supplémentaire.

---

# 3. Atomicité

Une Value est considérée comme indivisible.

Le Kernel ne s'intéresse jamais à sa représentation interne.

---

# 4. Neutralité

Une Value ne contient :

- aucune logique ;
- aucune règle ;
- aucune décision.

---

# 5. Utilisation

Une Value est utilisée pour construire des informations plus complexes.

---

# 6. Validation

Une Value est valide si :

✓ elle reste atomique ;

✓ elle possède une signification unique ;

✓ elle est indépendante de son implémentation.
