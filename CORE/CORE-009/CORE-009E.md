# CORE-009-E — Localisation

> Version : 1.0
>
> Statut : Fondation
>
> Type : Principes
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir le rôle de Space dans la localisation.

---

# 2. Principe

Space permet de situer des éléments sans définir leur représentation géométrique.

---

# 3. Comparaison

Deux localisations peuvent être comparées.

La nature de cette comparaison n'est pas définie par CORE.

---

# 4. Évolution

Une localisation peut évoluer.

Cette évolution est représentée par de nouveaux States et, le cas échéant, documentée par de nouveaux Events.

---

# 5. Validation

La localisation est conforme si elle reste indépendante de toute implémentation.
