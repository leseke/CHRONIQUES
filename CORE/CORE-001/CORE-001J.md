# CORE-001-J — Gouvernance

> Version : 1.0
>
> Statut : Fondation
>
> Type : Gouvernance
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les règles d'évolution de la bibliothèque CORE.

---

# 2. Principe

CORE constitue le socle conceptuel de Chroniques.

Toute modification doit être exceptionnelle.

---

# 3. Ajout d'une primitive

Une nouvelle primitive ne peut être introduite que si :

- elle est universelle ;
- elle est atomique ;
- elle ne peut être exprimée par les primitives existantes.

---

# 4. Modification d'une primitive

Toute modification doit :

- préserver la compatibilité conceptuelle ;
- être justifiée ;
- être documentée ;
- être validée par une ADR.

---

# 5. Dépréciation

Une primitive n'est jamais supprimée.

Elle peut être :

- Active ;
- Dépréciée ;
- Remplacée ;
- Archivée.

---

# 6. Compatibilité

Les évolutions de CORE doivent préserver la cohérence des bibliothèques dépendantes.

---

# 7. Traçabilité

Chaque évolution est historisée.

Les impacts documentaires sont identifiés avant validation.

---

# 8. Validation

Une évolution est acceptée si :

✓ elle améliore le modèle ;

✓ elle ne crée pas de duplication ;

✓ elle conserve les responsabilités existantes.

---

# 9. Contrat

CORE reste la référence officielle des concepts fondamentaux de Chroniques.

---

# Historique

Version 1.0

Création des règles de gouvernance de CORE.
