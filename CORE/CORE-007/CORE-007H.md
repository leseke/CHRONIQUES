---

# 1. Objectif

Définir les relations entre Event et les autres primitives du Kernel.

---

# 2. Relations

Un Event :

- concerne une ou plusieurs Entities ;
- peut concerner une Relation ;
- décrit une évolution de State ;
- appartient au Time ;
- peut être référencé.

---

# 3. Dépendances

Les Systems produisent des Events.

Les Events documentent les évolutions observées.

Les States représentent les nouvelles conditions du monde.

---

# 4. Validation

Les relations sont conformes si elles respectent les responsabilités définies dans CORE.
