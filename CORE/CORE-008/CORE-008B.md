# CORE-008-B — Définition

> Version : 1.0
>
> Statut : Fondation
>
> Type : Définition
>
> Bibliothèque : CORE

---

# 1. Définition

Time est la primitive représentant l'ordre temporel des faits observables.

---

# 2. Nature

Time ne décrit pas une durée.

Il décrit une position dans une succession.

---

# 3. Neutralité

CORE ne définit ni :

- secondes ;
- minutes ;
- heures ;
- ticks ;
- calendriers.

Ces notions appartiennent aux bibliothèques spécialisées.

---

# 4. Utilisation

Time permet de comparer plusieurs Events afin d'établir leur ordre.

---

# 5. Validation

La définition est conforme si :

✓ Time reste conceptuel ;

✓ aucune unité n'est imposée ;

✓ la chronologie peut être établie.
