# CORE-008-G — Invariants

> Version : 1.0
>
> Statut : Fondation
>
> Type : Invariants
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les propriétés toujours vraies de Time.

---

# 2. Invariants

## Invariant 1

Time permet toujours d'ordonner les Instants.

---

## Invariant 2

Chaque Instant occupe une position unique dans Time.

---

## Invariant 3

Time est indépendant de toute unité de mesure.

---

## Invariant 4

Time ne contient aucune logique métier.

---

## Invariant 5

Les Events peuvent être situés dans Time.

---

## Invariant 6

CORE n'impose ni temps continu ni temps discret.

---

# 3. Validation

Toute évolution de CORE doit préserver ces invariants.
