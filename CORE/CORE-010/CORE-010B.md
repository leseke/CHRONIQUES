# CORE-010-B — Définition

> Version : 1.0
>
> Statut : Fondation
>
> Type : Définition
>
> Bibliothèque : CORE

---

# 1. Définition

Lifecycle est la primitive représentant la continuité d'une primitive évolutive à travers le Time.

---

# 2. Nature

Lifecycle est descriptif.

Il représente une succession d'états et de faits observés.

---

# 3. Neutralité

Lifecycle ne définit :

- aucune règle ;
- aucun comportement ;
- aucun mécanisme d'évolution.

---

# 4. Utilisation

Lifecycle permet d'interpréter l'évolution cohérente d'une même continuité.

---

# 5. Validation

Lifecycle est valide si :

✓ il reste descriptif ;

✓ il représente une seule continuité ;

✓ il ne contient aucune logique.
