# 1. Objectif

Décrire les interactions entre Relation et les autres primitives du Kernel.

---

# 2. Relations

Une Relation :

- relie des Entities ;
- peut posséder un State ;
- peut contenir des Values ;
- peut être référencée ;
- peut évoluer au cours du Time ;
- peut être modifiée par un Event.

---

# 3. Dépendances

Une Relation complète les Entities.

Les Events décrivent l'évolution des Relations.

Les Systems interprètent ces évolutions.

---

# 4. Validation

Les interactions sont conformes si elles respectent les responsabilités définies dans CORE.
