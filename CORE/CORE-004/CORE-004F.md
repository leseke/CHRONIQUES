# CORE-004-F — Invariants

> Version : 1.0
>
> Statut : Fondation
>
> Type : Invariants
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les propriétés toujours vraies de la primitive Value.

---

# 2. Invariants

## Invariant 1

Une Value est atomique.

---

## Invariant 2

Une Value possède une seule signification.

---

## Invariant 3

Une Value est indépendante de la logique métier.

---

## Invariant 4

Une Value est exclusivement descriptive.

---

## Invariant 5

Une Value peut être remplacée sans modifier la structure du Component.

---

# 3. Validation

Toute évolution de CORE doit préserver ces invariants.
