# CORE-007-B — Définition

> Version : 1.0
>
> Statut : Fondation
>
> Type : Définition
>
> Bibliothèque : CORE

---

# 1. Définition

Un Event est une primitive représentant un fait survenu à un instant donné.

---

# 2. Nature

Un Event est descriptif.

Il documente un changement sans en être la cause.

---

# 3. Cause

La cause d'un changement appartient aux Systems.

L'Event décrit uniquement le résultat observable.

---

# 4. Temporalité

Tout Event est associé à un instant dans le Time.

---

# 5. Neutralité

Un Event ne contient :

- aucune décision ;
- aucune règle ;
- aucun comportement.

---

# 6. Validation

Un Event est valide si :

✓ il décrit un fait ;

✓ il est situé dans le temps ;

✓ il ne contient aucune logique.
