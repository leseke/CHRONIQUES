# 1. Définition

Une Relation est une primitive représentant un lien explicite entre deux ou plusieurs Entities.

---

# 2. Nature

Une Relation n'ajoute aucune logique.

Elle décrit uniquement qu'un lien existe.

---

# 3. Temporalité

Une Relation peut apparaître,

évoluer,

ou disparaître.

Ces évolutions sont indépendantes des Entities qu'elle relie.

---

# 4. Neutralité

Une Relation ne définit :

- aucune règle ;
- aucune décision ;
- aucun comportement.

---

# 5. Validation

Une Relation est valide si :

✓ les Entities concernées sont identifiables ;

✓ le lien est explicite ;

✓ aucune logique n'est embarquée.
