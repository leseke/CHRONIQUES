---

# 1. Objectif

Définir officiellement la primitive **Relation**.

Une Relation représente un lien conceptuel entre plusieurs Entities.

---

# 2. Mission

La Relation permet d'exprimer qu'une ou plusieurs Entities sont liées.

Elle décrit uniquement l'existence de ce lien.

---

# 3. Principe

Une Relation n'est pas une Entity.

Elle représente un fait conceptuel reliant des Entities.

---

# 4. Portée

Une Relation peut représenter :

- une appartenance ;
- une dépendance ;
- une proximité ;
- une hiérarchie ;
- une association.

Ces catégories sont illustratives.

---

# 5. Responsabilités

Une Relation :

- relie des Entities ;
- peut évoluer ;
- peut être observée.

Elle ne contient aucune logique métier.

---

# 6. Validation

Une Relation est conforme si :

✓ elle relie explicitement plusieurs Entities ;

✓ elle reste indépendante de son implémentation ;

✓ elle ne contient aucun comportement.
