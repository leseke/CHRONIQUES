---

# 1. Objectif

Décrire les relations entre Space et les autres primitives du Kernel.

---

# 2. Relations

Space :

- permet de situer une Entity ;
- peut être associé à une Relation ;
- permet de contextualiser certains States ;
- peut être référencé.

---

# 3. Dépendances

Space fournit uniquement un contexte de localisation.

Il ne modifie ni les Entities, ni les Relations, ni les States.

---

# 4. Validation

Les relations sont conformes si elles respectent les responsabilités définies dans CORE.
