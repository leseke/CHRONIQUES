# 1. Objectif

Définir officiellement la primitive **Space**.

Space fournit le cadre conceptuel permettant de situer les éléments du monde.

---

# 2. Mission

Space permet de localiser les primitives qui possèdent une existence spatiale.

---

# 3. Principe

Space ne décrit pas une géométrie.

Il fournit uniquement un référentiel de localisation.

---

# 4. Portée

Space permet notamment :

- de situer une Entity ;
- de situer une Relation ;
- de comparer des localisations.

---

# 5. Responsabilités

Space :

- localise ;
- fournit un référentiel spatial ;
- permet la comparaison des positions.

Il ne définit aucune représentation géométrique.

---

# 6. Validation

Space est conforme si :

✓ il permet la localisation ;

✓ il reste indépendant de toute représentation technique ;

✓ il ne contient aucune logique métier.
