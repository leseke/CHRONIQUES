# CORE-003-G — Invariants

> Version : 1.0
>
> Statut : Fondation
>
> Type : Invariants
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les propriétés toujours vraies pour la primitive Component.

---

# 2. Invariants

## Invariant 1

Un Component appartient toujours à une Entity.

---

## Invariant 2

Un Component possède une responsabilité unique.

---

## Invariant 3

Un Component ne contient aucune logique métier.

---

## Invariant 4

Un Component est exclusivement descriptif.

---

## Invariant 5

Un Component peut évoluer sans modifier l'identité de son Entity.

---

## Invariant 6

Les informations d'un Component doivent rester cohérentes avec sa responsabilité.

---

# 3. Validation

Toute évolution de CORE doit préserver ces invariants.
