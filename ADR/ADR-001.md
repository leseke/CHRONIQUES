# ADR-001 — Création de la bibliothèque CORE

Statut : Accepté

Date : 2026

---

# Contexte

Les premiers documents ACT ont révélé que plusieurs concepts fondamentaux
étaient utilisés dans de nombreuses bibliothèques.

Exemples :

- Event
- Entity
- State
- Time
- Space
- Relation
- Identity
- Value

Ces concepts ne relèvent ni du gameplay,
ni du monde,
ni de l'implémentation.

Ils constituent le langage fondamental du moteur.

---

# Décision

Créer une nouvelle bibliothèque racine :

CORE

placée entre

STANDARDS

et

les bibliothèques métier.

Architecture :

MASTER

↓

STANDARDS

↓

CORE

↓

GDB

ACT

PLN

↓

TECH

---

# Conséquences

CORE devient la source officielle
des concepts fondamentaux.

Toutes les autres bibliothèques
utilisent CORE
sans le redéfinir.

---

# Avantages

- suppression des duplications

- responsabilités claires

- langage commun

- meilleure traçabilité

- meilleure évolutivité

---

# Inconvénients

Une légère réorganisation documentaire.

---

# Statut

Accepté.
