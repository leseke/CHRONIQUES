# CORE-001-B — Philosophie

---

# Principe fondamental

Le monde est un graphe dynamique de concepts.

Il n'existe aucun objet privilégié.

Tout est représenté de manière uniforme.

---

# Universalité

Les primitives de CORE sont indépendantes :

- de l'époque ;
- de la technologie ;
- du gameplay ;
- de la narration ;
- de l'interface.

---

# Minimalisme

CORE cherche le plus petit ensemble de concepts capable de décrire tout Chroniques.

Chaque primitive supplémentaire augmente la complexité.

Elle doit donc être justifiée.

---

# Composition

Les comportements complexes émergent par composition.

Jamais par duplication.

---

# Immutabilité

Les définitions conceptuelles restent stables.

Seuls les états évoluent.

---

# Traçabilité

Toute information du projet doit pouvoir être reliée aux primitives de CORE.
