# CORE-009-J — Gouvernance

> Version : 1.0
>
> Statut : Fondation
>
> Type : Gouvernance
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les règles d'évolution de la primitive Space.

---

# 2. Principe

Space doit rester une primitive universelle de localisation.

Il ne doit jamais dépendre d'une représentation géométrique particulière.

---

# 3. Évolution

Toute évolution doit :

- préserver les invariants ;
- respecter la neutralité conceptuelle ;
- être documentée ;
- être validée par une ADR.

---

# 4. Compatibilité

Les évolutions ne doivent pas remettre en cause les autres primitives du Kernel.

---

# 5. Dépréciation

Une propriété peut être dépréciée.

La primitive Space ne peut être supprimée.

---

# 6. Validation

Toute modification doit préserver le rôle de Space comme référentiel conceptuel de localisation.
