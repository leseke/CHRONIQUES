# CORE-009-D — Composition

> Version : 1.0
>
> Statut : Fondation
>
> Type : Contrat conceptuel
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir la composition conceptuelle de Space.

---

# 2. Principe

Space est composé de localisations appartenant à un même référentiel.

CORE ne définit pas leur représentation.

---

# 3. Localisation

Une localisation représente une position dans Space.

Elle ne possède aucune signification métier.

---

# 4. Référentiel

Toutes les localisations sont interprétées relativement au même référentiel spatial.

---

# 5. Neutralité

CORE ne définit :

- aucune dimension ;
- aucune métrique ;
- aucune précision.

---

# 6. Validation

Space est conforme si les localisations peuvent être comparées au sein d'un même référentiel.
