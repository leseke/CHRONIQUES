# CORE-007-G — Invariants

> Version : 1.0
>
> Statut : Fondation
>
> Type : Invariants
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les propriétés toujours vraies de la primitive Event.

---

# 2. Invariants

## Invariant 1

Un Event représente toujours un fait.

---

## Invariant 2

Un Event est immuable.

---

## Invariant 3

Un Event appartient au Time.

---

## Invariant 4

Un Event ne contient aucune logique.

---

## Invariant 5

Un Event est traçable.

---

## Invariant 6

Un Event ne peut être modifié après sa création.

---

# 3. Validation

Toute évolution de CORE doit préserver ces invariants.
