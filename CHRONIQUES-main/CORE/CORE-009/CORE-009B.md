# CORE-009-B — Définition

> Version : 1.0
>
> Statut : Fondation
>
> Type : Définition
>
> Bibliothèque : CORE

---

# 1. Définition

Space est la primitive représentant le référentiel spatial du monde.

---

# 2. Nature

Space permet d'associer une localisation aux éléments concernés.

---

# 3. Neutralité

CORE ne définit ni :

- coordonnées ;
- dimensions ;
- métriques ;
- projections ;
- géométrie.

Ces notions appartiennent aux bibliothèques spécialisées.

---

# 4. Utilisation

Space permet de déterminer où se situe un élément relativement à un référentiel.

---

# 5. Validation

La définition est conforme si :

✓ Space reste conceptuel ;

✓ aucune représentation spatiale n'est imposée ;

✓ la localisation est possible.
