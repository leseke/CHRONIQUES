# 1. Objectif

Définir officiellement la primitive **Time**.

Time fournit le cadre conceptuel permettant de situer les faits dans une succession.

---

# 2. Mission

Time permet d'ordonner les évolutions du monde.

Il constitue le référentiel temporel de Chroniques.

---

# 3. Principe

Time ne mesure pas le temps.

Il fournit uniquement un ordre entre les événements.

---

# 4. Portée

Time permet notamment :

- de situer un Event ;
- d'ordonner plusieurs Events ;
- de représenter une évolution.

---

# 5. Responsabilités

Time :

- ordonne ;
- situe ;
- permet la chronologie.

Il ne provoque aucune évolution.

---

# 6. Validation

Time est conforme si :

✓ il permet d'ordonner les Events ;

✓ il reste indépendant de toute représentation technique ;

✓ il ne contient aucune logique métier.
