---

# 1. Objectif

Décrire les interactions entre Time et les autres primitives.

---

# 2. Relations

Time :

- situe les Events ;
- permet l'évolution des States dans une chronologie ;
- participe au Lifecycle des Entities ;
- peut être référencé.

---

# 3. Dépendances

Time fournit le contexte temporel du Kernel.

Il n'introduit aucune règle d'évolution.

---

# 4. Validation

Les interactions sont conformes si elles respectent les responsabilités définies dans CORE.
