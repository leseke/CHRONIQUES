# CORE-010-A — Mission

> Version : 1.0
>
> Statut : Fondation
>
> Type : Mission
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir officiellement la primitive **Lifecycle**.

Lifecycle représente la continuité d'une primitive évolutive au cours du Time.

---

# 2. Mission

Lifecycle organise la succession cohérente des States et des Events associés à une même continuité.

---

# 3. Principe

Lifecycle ne provoque aucune évolution.

Il représente uniquement une continuité observée.

---

# 4. Portée

Lifecycle peut notamment représenter la continuité :

- d'une Entity ;
- d'une Relation.

---

# 5. Responsabilités

Lifecycle :

- représente une continuité ;
- organise une évolution ;
- fournit un historique cohérent.

Il ne contient aucune logique métier.

---

# 6. Validation

Lifecycle est conforme si :

✓ il représente une seule continuité ;

✓ il reste descriptif ;

✓ il ne provoque aucun changement.
