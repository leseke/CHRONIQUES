# CORE-001-H — Terminologie

> Version : 1.0
>
> Statut : Fondation
>
> Type : Terminologie
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir le vocabulaire officiel utilisé dans CORE.

Cette terminologie est normative pour l'ensemble du projet.

---

# 2. Primitive

Concept fondamental ne pouvant être décomposé en concepts plus simples dans le cadre de Chroniques.

---

# 3. Entity

Élément identifiable pouvant exister dans la simulation.

---

# 4. Component

Élément décrivant une partie d'une Entity.

Un Component ne possède pas d'existence autonome.

---

# 5. State

Ensemble des informations représentant la condition actuelle d'un Component ou d'une Entity.

---

# 6. Value

Information élémentaire représentant une mesure, une quantité ou une propriété.

---

# 7. Relation

Lien explicite entre deux ou plusieurs Entities.

---

# 8. Event

Fait survenu dans la simulation décrivant une modification de l'état du monde.

---

# 9. Time

Référentiel permettant d'ordonner les événements.

---

# 10. Space

Référentiel permettant de localiser les entités.

---

# 11. Reference

Lien stable permettant d'identifier ou de relier un concept, une donnée ou un document.

---

# 12. Lifecycle

Succession d'états caractérisant l'évolution d'un concept au cours de son existence.

---

# 13. Validation

Toute la documentation de Chroniques doit utiliser cette terminologie sans ambiguïté.

---
