# CORE-002-J — Gouvernance

> Version : 1.0
>
> Statut : Fondation
>
> Type : Gouvernance
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir les règles d'évolution de la primitive Entity.

---

# 2. Évolution

Toute modification de la définition d'Entity doit :

- préserver la compatibilité conceptuelle ;
- être documentée ;
- être validée par une ADR.

---

# 3. Compatibilité

Les évolutions ne doivent pas remettre en cause les bibliothèques dépendantes.

---

# 4. Dépréciation

Une règle ou une propriété peut être dépréciée.

La primitive Entity ne peut être supprimée.

---

# 5. Validation

Toute évolution est analysée avant son intégration.
