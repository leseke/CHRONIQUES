# CORE-010-E — Continuité

> Version : 1.0
>
> Statut : Fondation
>
> Type : Principes
>
> Bibliothèque : CORE

---

# 1. Objectif

Définir le rôle de Lifecycle dans la représentation de la continuité.

---

# 2. Principe

Lifecycle représente l'évolution observée d'une même continuité.

---

# 3. Succession

La continuité est constituée d'une succession chronologique de States et d'Events.

---

# 4. Cohérence

Tous les éléments d'un Lifecycle concernent la même primitive évolutive.

---

# 5. Évolution

Une évolution ajoute de nouveaux States ou de nouveaux Events.

Elle ne modifie jamais les éléments historiques.

---

# 6. Validation

La continuité est conforme si elle reste chronologiquement cohérente.
